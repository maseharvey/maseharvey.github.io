# Mase Bio Site

Plain HTML/CSS/JS personal site with a light-blue CRT/static aesthetic.

## Files
- `index.html`
- `style.css`
- `script.js`
- `profile.jpg`

## GitHub Pages
Create a repository named `YOUR_USERNAME.github.io`, upload these files to the root, then go to **Settings → Pages** and choose **Deploy from a branch**, your main branch, and `/ (root)`.
